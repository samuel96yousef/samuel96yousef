# Koptisk bönbok

Arabisk-svensk bön- och läsningsapp för en koptisk församling i Sverige.

| Mapp | Innehåll |
| --- | --- |
| [`mobile/`](mobile/README.md) | Appen, byggd med Expo (React Native) för iPhone och Android. Börja här. |
| [`prototype/`](prototype/README.md) | Webbprototypen från steg 1 som designen utgår från. |

Texterna kommer från CopticPrayers-APK:n och committas inte, eftersom
rättigheterna till de svenska översättningarna inte är utredda. Båda
mapparna har ett skript som skapar texterna lokalt från APK:n.
