# Simple Note App

A clean, minimalist note-taking application built with vanilla HTML, CSS, and JavaScript.

## Features

- Create notes with titles and content
- Delete notes individually
- Automatic local storage persistence
- Responsive design
- Beautiful gradient UI
- Keyboard shortcuts

## Usage

### Getting Started

1. Open `index.html` in your web browser
2. Start taking notes!

### Adding Notes

- Enter a title (optional) in the first input field
- Write your note content in the text area
- Click "Add Note" button or use keyboard shortcuts:
  - Press `Enter` in the title field
  - Press `Ctrl+Enter` in the content area

### Deleting Notes

- Click the "Delete" button on any note
- Confirm the deletion when prompted

### Data Persistence

Notes are automatically saved to your browser's local storage, so they'll be there when you return!

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and responsive design
- `app.js` - JavaScript functionality and data management

## Browser Compatibility

Works with all modern browsers that support:
- ES6 JavaScript
- Local Storage API
- CSS Grid
